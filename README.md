# HalloweenApp

Esta es una aplicación de Android desarrollada para Halloween.

## Características

- **Galería:** Una galería de imágenes con temática de Halloween.
- **Juego:** Un juego simple con temática de Halloween.
- **Tareas:** Una lista de tareas relacionadas con Halloween.
- **Videos:** Una sección para ver videos con temática de Halloween (por ejemplo, Thriller de Michael Jackson).

## Tecnologías Utilizadas

- Kotlin
- Jetpack Compose
- Android Studio

## Empezando

Para obtener una copia local y ponerla en marcha, sigue estos sencillos pasos.

### Prerrequisitos

- Android Studio
- Android SDK

### Instalación

1. Clona el repositorio
   ```sh
   git clone https://github.com/pablocarrillopunina/HalloweenApp.git
   ```
2. Abre el proyecto en Android Studio.
3. Construye y ejecuta la aplicación en un emulador o en un dispositivo físico.
